# LR-608 0.99.31 — Release notes

**Release date:** 14 October 2026  
**Platform:** Windows VST3  
**Project:** https://github.com/Lo-lo78/LR-608

LR-608 0.99.31 is a maintenance and documentation release of the accessible, synthesized drum machine.

## Changes since 0.99.3

- Fixed the About panel keyboard shortcuts: **Ctrl+A** selects all About text; **Ctrl+C** copies selected text to the clipboard. Keyboard selection with Shift+arrow keys continues to work.
- Updated the About panel, CMake project version, README, and eight-language Help to **0.99.31**, dated **14 October 2026**.
- Brought the main documentation up to date with the current inventory of **90 playable synthesis engines plus Off**, and per-Slot sound and FX controls, from the prior documentation refresh.

The existing synth engines, sound processing, parameter catalogues, preset format, and MIDI/routing behaviour have not been modified for this release.

The source archive is not a compiled VST3. Build and test through GitHub Actions and verify the About clipboard shortcuts in your DAW before publishing the binary.
