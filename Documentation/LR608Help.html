LR-608 0.99.31: accessible drum synthesizer

LR-608 is a keyboard-first VST3 drum synthesizer derived from the original LR-608 JSFX. It combines analogue-style 808/909/Simmons circuits with Saike synthesis, FM, physical modelling, metallic, acoustic and experimental engines. The instrument provides 128 independent Slots, layering, 128-voice polyphony and 32 stereo output pairs.

Engine count and version

The engine selector contains 90 playable sound engines plus Off - No sound. This number counts synthesised sound engines, not Slots or factory kits. The release version is 0.99.31, dated 14 October 2026.

This is an instrument that synthesises percussion; no external drum WAV library is required. For keyboard-only use, Alt+H opens the language selector, while Alt+A opens the accessible About dialog.

Slots, engines and layering

Each Slot owns an Engine, MIDI Note, MIDI Choke Trigger and Target, Output, a Sound page and an FX page. Several Slots may share the same MIDI Note, so one key can trigger layered sounds. Changing Engine never changes the Slot MIDI Note. Off - No sound empties a Slot. Up to eight layers may be assigned to one MIDI key when copying/pasting.

The engine bank includes Kicks, Snares, Claps, Rims, Low/Mid/High Toms, closed/open Hi-Hats, Crash/Ride, Maracas, Clave/Cowbell/Timbales and multiple Zap engines. Some families expose circuit-specific controls such as noise granulation, pitch-decay curves, body coupling, compression or modal parameters.

Sound and FX pages

Alt+F switches the current Slot between Sound parameters and FX parameters. The Sound page contains the selected engine's synthesis controls. The FX page contains the Slot processing shared by the engines: Pan, Ping Pong Pan Depth, LFO, Voice Overlap, Low Pass and High Pass filters with resonance, FX Envelope, Delay, Degrade, Roll Division and Accent controls.

The per-Slot LFO offers Wave, One Shot, One Shot Percent, Phase, Frequency in BPM, Env Rate, Delay, Smooth, Square PWM, Upper/Lower Squash and bipolar depths for Volume, Low Pass, High Pass and Pan. The FX Envelope has Attack and Decay with bipolar depths for Volume, LP, HP and Pan. The Delay provides Wet, Time, Feedback, Speed Glide, Pitch per repeat, feedback filter and resonance, plus independent Left/Right offsets. Degrade provides Amount, Bits, Hold and Jitter.

MIDI, voices, choke and routing

Incoming MIDI always plays normally. Alt+M toggles MIDI-key editing. While enabled, repeatedly playing a MIDI key cycles through the active Slots assigned to that note without moving keyboard focus. Voice Overlap is stored per Slot. Choke Trigger is the incoming note that causes a choke; Choke Target is the note whose active voices are stopped. Every matching link is evaluated.

Each Slot can be routed independently to Stereo 1/2 through Stereo 63/64. Multiple Slots may share an output and routing is saved in presets.

Main area and parameter grid

The main area has six columns: Slot, Engine, MIDI Note, MIDI Choke Trigger, MIDI Choke Target and Output. Left/Right changes column; Up/Down, Page Up/Down and Home/End change its value. F2 on Slot renames it. Tab or Alt+L enters the parameter grid at the remembered position; Esc returns to the remembered main column.

In the grid, arrows move by row/column and letters or digits jump to the next parameter beginning with that character. Page Up/Down moves five items inside the current column. Home/End moves to the top/bottom of the current column; Ctrl+Home/Ctrl+End moves to the first/last parameter. Alt+. adds a row to each grid column and Alt+, removes one; the preference is remembered.

Enter moves between Grid and Value. Alt+V focuses Value. Alt+E opens numeric editing. In Grid or Value, Up/Down changes the value, Left/Right changes step width, Page Up/Down makes a larger change, Home/End selects a boundary and Backspace resets the parameter.

MIDI-key editing

With MIDI editing enabled, play the source key. Alt+C or Ctrl+C copies all its layers; Alt+X or Ctrl+X cuts them. Play the destination key, then use Alt+Shift+V or Ctrl+V. Existing destination layers are preserved, up to eight layers total; paste is atomic if there is not enough space. Alt+Delete removes only the selected layer. Alt+Shift+Delete removes all layers on the captured MIDI key. Plain Delete is protected and erases nothing.

Presets, reports, Help and About

Alt+B opens the accessible preset browser. Up/Down, Page, Home/End navigate; letters and numbers cycle by initial. Enter loads the selection. Escape, Alt+C or a second Alt+B closes without loading and returns focus to the previous control. Delete asks before deleting a user preset; Factory presets are protected. Alt+S saves the complete kit, including from inside the browser. Alt++/Alt+- selects next/previous preset.

Alt+R announces filled and empty Slot totals; pressing R twice while holding Alt opens the grouped Slot report. Alt+T announces the current Engine without moving focus. Alt+H opens the Help language menu. Alt+A opens the accessible About panel for LR-608 0.99.31.

Global

Alt+G opens Global. It contains Roll Division, Roll Shuffle, Roll Second Hit Velocity Reduction and Master Volume. Enter confirms changes; Escape cancels and restores the previous Global values.

LR-608 0.99.31: sintetizzatore di batteria accessibile

LR-608 è un drum synthesizer VST3 pensato per l’uso da tastiera e derivato dal JSFX LR-608 originale. Riunisce circuiti in stile 808/909/Simmons, sintesi Saike, FM, modelli fisici, motori metallici, acustici e sperimentali. Offre 128 Slot indipendenti, layering, 128 voci e 32 coppie di uscite stereo.

Numero di motori e versione

Il selettore comprende 90 motori sonori utilizzabili più Off - No sound. Il numero si riferisce ai motori di sintesi, non agli Slot o ai kit di fabbrica. La versione è 0.99.31, pubblicata il 14 ottobre 2026.

Lo strumento sintetizza le percussioni: non richiede una libreria esterna di file WAV di batteria. Alt+H apre la scelta della lingua dell’Help, mentre Alt+A apre la finestra About accessibile.

Slot, motori e layer

Ogni Slot possiede Engine, MIDI Note, MIDI Choke Trigger e Target, Output, una pagina Sound e una pagina FX. Più Slot possono condividere la stessa MIDI Note e quindi suonare in layer. Cambiare Engine non modifica la MIDI Note. Off - No sound svuota lo Slot. Con copia/incolla si possono assegnare fino a otto layer allo stesso tasto MIDI.

I motori comprendono Kick, Snare, Clap, Rim, Low/Mid/High Tom, Hi-Hat chiusi e aperti, Crash/Ride, Maracas, Clave/Cowbell/Timbales e numerosi Zap. Alcune famiglie espongono controlli specifici come granulazione del noise, curve di pitch decay, body coupling, compressione o parametri modali.

Pagine Sound e FX

Alt+F commuta lo Slot corrente fra Sound parameters e FX parameters. Sound contiene i controlli di sintesi del motore scelto. FX contiene l’elaborazione comune dello Slot: Pan, Ping Pong Pan Depth, LFO, Voice Overlap, filtri Low Pass e High Pass con risonanza, FX Envelope, Delay, Degrade, Roll Division e controlli Accent.

L’LFO per Slot offre Wave, One Shot, One Shot Percent, Phase, Frequency in BPM, Env Rate, Delay, Smooth, Square PWM, Upper/Lower Squash e profondità bipolari verso Volume, Low Pass, High Pass e Pan. L’FX Envelope ha Attack e Decay con profondità bipolari verso Volume, LP, HP e Pan. Il Delay comprende Wet, Time, Feedback, Speed Glide, Pitch per ripetizione, filtro del feedback e risonanza, più offset Left/Right indipendenti. Degrade comprende Amount, Bits, Hold e Jitter.

MIDI, voci, choke e routing

Il MIDI in ingresso suona sempre normalmente. Alt+M attiva/disattiva l’editing tramite tastiera MIDI. Quando è attivo, premendo ripetutamente un tasto MIDI si ciclano gli Slot attivi assegnati a quella nota senza spostare il focus. Voice Overlap è memorizzato per Slot. Choke Trigger è la nota che provoca il choke; Choke Target è la nota le cui voci attive vengono fermate. Tutti i collegamenti corrispondenti vengono eseguiti.

Ogni Slot può essere inviato indipendentemente da Stereo 1/2 fino a Stereo 63/64. Più Slot possono condividere la stessa uscita e il routing viene salvato nei preset.

Area principale e griglia parametri

L’area principale ha sei colonne: Slot, Engine, MIDI Note, MIDI Choke Trigger, MIDI Choke Target e Output. Sinistra/Destra cambia colonna; Su/Giù, Pagina Su/Giù e Home/Fine ne cambiano il valore. F2 sullo Slot lo rinomina. Tab o Alt+L entra nella griglia alla posizione ricordata; Esc torna alla colonna principale ricordata.

Nella griglia le frecce si muovono per righe e colonne; lettere o cifre cercano il parametro successivo con quell’iniziale. Pagina Su/Giù sposta di cinque elementi nella colonna corrente. Home/Fine va all’inizio/fine della colonna; Ctrl+Home/Ctrl+Fine va al primo/ultimo parametro. Alt+. aumenta di una riga ogni colonna della griglia e Alt+, la riduce; l’impostazione viene ricordata.

Invio passa fra Grid e Value. Alt+V porta a Value. Alt+E apre l’editor numerico. In Grid o Value, Su/Giù modifica il valore, Sinistra/Destra cambia l’ampiezza dello step, Pagina Su/Giù fa una modifica maggiore, Home/Fine sceglie un estremo e Backspace ripristina il parametro.

Editing dei tasti MIDI

Con MIDI editing attivo, suona il tasto sorgente. Alt+C o Ctrl+C copia tutti i layer; Alt+X o Ctrl+X li taglia. Suona il tasto destinazione, poi usa Alt+Shift+V o Ctrl+V. I layer già presenti restano e il totale massimo è otto; se non c’è spazio l’incolla non modifica nulla. Alt+Delete elimina solo il layer selezionato. Alt+Shift+Delete elimina tutti i layer del tasto MIDI catturato. Delete da solo è protetto e non cancella nulla.

Preset, report, Help e About

Alt+B apre il browser accessibile dei preset. Su/Giù, Pagina, Home/Fine navigano; lettere e numeri ciclano per iniziale. Invio carica la selezione. Esc, Alt+C o un secondo Alt+B chiudono senza caricare e riportano il focus al controllo precedente. Delete chiede conferma prima di eliminare un preset utente; i Factory sono protetti. Alt+S salva il kit completo, anche dall’interno del browser. Alt++/Alt+- sceglie preset successivo/precedente.

Layer: nell'area Slot, dopo Engine, la casella Layer mostra Layer 1, Layer 2 e così via, seguiti da Add Layer. Usare le frecce per navigare e premere Invio su Add Layer per creare il successivo con Engine Off. Massimo otto layer per nota MIDI; i layer vuoti appena creati rimangono salvati nel progetto.

Alt+R annuncia gli Slot pieni e vuoti; premendo R due volte mantenendo Alt si apre il report raggruppato. Alt+T annuncia l’Engine corrente senza spostare il focus. Alt+H apre il menu lingue dell’Help. Alt+A apre il pannello About accessibile di LR-608 0.99.31.

Global

Alt+G apre Global. Contiene Roll Division, Roll Shuffle, Roll Second Hit Velocity Reduction e Master Volume. Invio conferma; Esc annulla e ripristina i valori Global precedenti.

LR-608 синтезирует ударные звуки и не требует внешней библиотеки WAV. В FX эффект Delay имеет Wet, Time, Feedback, Glide, Pitch каждого повтора, фильтр с резонансом и отдельные смещения Left/Right; Degrade имеет Amount, Bits, Hold и Jitter. LFO и FX Envelope поддерживают биполярную модуляцию Volume, Low Pass, High Pass и Pan.

Slots, Sound и FX

Каждый Slot хранит Engine, MIDI Note, Choke Trigger/Target, Output и две страницы параметров. Alt+F переключает Sound и FX. Sound содержит синтез движка; FX — Pan, Ping Pong Pan, LFO, Voice Overlap, LP/HP с резонансом, FX Envelope, Delay, Degrade, Roll Division и Accent. LFO имеет форму, One Shot, фазу, частоту BPM, delay, smoothing/PWM/squash и биполярные глубины Volume/LP/HP/Pan. FX Envelope имеет Attack/Decay и биполярные глубины. Delay включает Wet, Time, Feedback, Glide, Pitch на повтор, фильтр/резонанс и L/R offsets.

Навигация и редактирование

Главная область: Slot, Engine, MIDI Note, Choke Trigger, Choke Target, Output. Стрелки меняют колонку/значение; F2 переименовывает Slot. Tab или Alt+L открывает Grid; Escape возвращает к запомненной колонке. Буквы/цифры ищут по первой букве. Page перемещает на пять элементов; Home/End — край колонки; Ctrl+Home/End — первый/последний параметр. Alt+./Alt+, меняет число строк. Enter переключает Grid/Value, Alt+V фокусирует Value, Alt+E открывает числовой редактор.

MIDI, presets и служебные функции

Alt+M включает MIDI-редактирование. Alt+C/Ctrl+C копирует слои; Alt+X/Ctrl+X вырезает; Alt+Shift+V или Ctrl+V вставляет до восьми слоёв. Alt+Delete удаляет только выбранный слой; Alt+Shift+Delete удаляет все слои захваченной MIDI-клавиши; обычный Delete ничего не удаляет. Slot можно направить от Stereo 1/2 до 63/64.

Alt+B открывает браузер; буквы/цифры циклически выбирают по первой букве, Enter загружает, Escape/Alt+C/Alt+B отменяет. Alt+S сохраняет. Alt++/- меняет preset. Alt+R сообщает Slots, двойное R открывает отчёт. Alt+T сообщает Engine. Alt+G открывает Global (Roll Division, Shuffle, уменьшение второго удара, Master Volume): Enter подтверждает, Escape отменяет. Alt+H — Help, Alt+A — About.

LR-608 0.99.31：无障碍鼓合成器

LR-608 是以键盘操作为核心的 VST3 鼓合成器，源自原始 LR-608 JSFX。它提供 128 个 Slot、分层、128 声部和 32 组立体声输出，并包含 808/909/Simmons、Saike、FM、物理建模、原声、金属和实验性引擎。

音源数量和版本

引擎选择器包含 90 个可发声的合成引擎，另有 Off - No sound 选项。该数字不是 Slot 数或预设套件数。当前版本为 0.99.31，发布日期为 2026 年 10 月 14 日。

LR-608 直接合成打击乐声音，无需外部 WAV 采样库。FX 中的 Delay 有 Wet、Time、Feedback、Glide、每次重复的 Pitch、带共振的滤波器和独立 Left/Right 偏移；Degrade 提供 Amount、Bits、Hold、Jitter。LFO 与 FX Envelope 支持对 Volume、Low Pass、High Pass、Pan 的双极性调制。

Slot、Sound 与 FX

每个 Slot 保存 Engine、MIDI Note、Choke Trigger/Target、Output 和两页参数。Alt+F 在 Sound 与 FX 之间切换。Sound 是当前引擎的合成参数；FX 包含 Pan、Ping Pong Pan、LFO、Voice Overlap、带共振的 LP/HP、FX Envelope、Delay、Degrade、Roll Division 和 Accent。LFO 具有波形、One Shot、相位、BPM 频率、Delay、Smooth/PWM/Squash，以及到 Volume/LP/HP/Pan 的双极深度。FX Envelope 有 Attack/Decay 和双极深度。Delay 包含 Wet、Time、Feedback、Glide、每次重复 Pitch、反馈滤波/共振及左右独立 Offset。

导航与编辑

主区域包括 Slot、Engine、MIDI Note、Choke Trigger、Choke Target、Output。方向键改变列/数值；F2 重命名 Slot。Tab 或 Alt+L 进入 Grid；Escape 返回记忆的主列。字母/数字按首字符查找。Page 每次移动五项；Home/End 到当前列边界；Ctrl+Home/End 到第一/最后参数。Alt+./Alt+, 改变网格行数。Enter 在 Grid/Value 间切换，Alt+V 聚焦 Value，Alt+E 打开数字编辑。

MIDI、预设与工具

Alt+M 开关 MIDI 编辑。Alt+C/Ctrl+C 复制层；Alt+X/Ctrl+X 剪切；Alt+Shift+V 或 Ctrl+V 粘贴，最多八层。Alt+Delete 只删除当前层；Alt+Shift+Delete 删除捕获 MIDI 键的全部层；单独 Delete 不会删除。每个 Slot 可路由到 Stereo 1/2 至 63/64。

Alt+B 打开预设浏览器；字母/数字按首字符循环，Enter 加载，Escape/Alt+C/Alt+B 取消。Alt+S 保存。Alt++/- 切换预设。Alt+R 播报 Slot，双按 R 打开报告。Alt+T 播报 Engine。Alt+G 打开 Global（Roll Division、Shuffle、第二击衰减、Master Volume）：Enter 确认，Escape 取消。Alt+H 打开 Help，Alt+A 打开 About。

LR-608 0.99.31：アクセシブル・ドラムシンセサイザー

LR-608 はキーボード操作を中心に設計された VST3 ドラムシンセで、元の LR-608 JSFX を基にしています。128 Slot、レイヤー、128 ボイス、32 系統のステレオ出力を備え、808/909/Simmons、Saike、FM、物理モデル、アコースティック、メタリック、実験的エンジンを収録します。

エンジン数とバージョン

エンジン選択には 90 種類の発音可能な音源エンジンと、別項目の Off - No sound があります。この数は Slot 数やファクトリーキット数ではありません。バージョンは 0.99.31、リリース日は 2026 年 10 月 14 日です。

LR-608 は打楽器の音を合成するため、外部 WAV サンプルライブラリは不要です。FX の Delay には Wet、Time、Feedback、Glide、反復ごとの Pitch、共振付きフィルターと独立 Left/Right Offset があります。Degrade は Amount、Bits、Hold、Jitter を備え、LFO と FX Envelope は Volume、Low Pass、High Pass、Pan をバイポーラで変調します。

Slot、Sound、FX

各 Slot は Engine、MIDI Note、Choke Trigger/Target、Output と 2 ページのパラメーターを保持します。Alt+F で Sound と FX を切り替えます。Sound はエンジンの合成パラメーター、FX は Pan、Ping Pong Pan、LFO、Voice Overlap、共振付き LP/HP、FX Envelope、Delay、Degrade、Roll Division、Accent です。LFO は Wave、One Shot、Phase、BPM Frequency、Delay、Smooth/PWM/Squash、Volume/LP/HP/Pan へのバイポーラ Depth を持ちます。FX Envelope は Attack/Decay とバイポーラ Depth、Delay は Wet、Time、Feedback、Glide、反復ごとの Pitch、Feedback Filter/Resonance、独立 L/R Offset を持ちます。

ナビゲーションと編集

メイン領域は Slot、Engine、MIDI Note、Choke Trigger、Choke Target、Output。矢印で列/値を変更し、F2 で Slot 名を変更します。Tab または Alt+L で Grid、Escape で記憶した列へ戻ります。文字/数字で先頭文字検索。Page は 5 項目移動、Home/End は現在列の端、Ctrl+Home/End は最初/最後のパラメーター。Alt+./Alt+, で Grid の行数を変更します。Enter は Grid/Value を切り替え、Alt+V は Value、Alt+E は数値編集です。

MIDI、プリセット、ユーティリティ

Alt+M で MIDI 編集を切替。Alt+C/Ctrl+C でレイヤーをコピー、Alt+X/Ctrl+X でカット、Alt+Shift+V または Ctrl+V で最大 8 レイヤーまでペーストします。Alt+Delete は選択レイヤーのみ、Alt+Shift+Delete は捕捉した MIDI キーの全レイヤーを削除します。Delete 単独では削除しません。各 Slot は Stereo 1/2～63/64 にルーティングできます。

Alt+B はプリセットブラウザー。文字/数字で先頭文字巡回、Enter でロード、Escape/Alt+C/Alt+B でキャンセル。Alt+S で保存、Alt++/- でプリセット変更。Alt+R は Slot 数、R を 2 回でレポート。Alt+T は Engine を通知。Alt+G は Global（Roll Division、Shuffle、Second Hit Reduction、Master Volume）で Enter 確定、Escape 取消。Alt+H は Help、Alt+A は About。
